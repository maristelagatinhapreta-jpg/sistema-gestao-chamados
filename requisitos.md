# Requisitos do Sistema

## Requisitos Funcionais

### RF01 - Cadastro de Usuários
O sistema deve permitir o cadastro de usuários.

### RF02 - Login
O sistema deve permitir autenticação por e-mail e senha.

### RF03 - Abertura de Chamados
O usuário deve conseguir registrar uma solicitação de suporte.

### RF04 - Consulta de Chamados
O usuário deve visualizar seus chamados.

### RF05 - Atualização de Status
O suporte deve atualizar o andamento dos chamados.

### RF06 - Encerramento de Chamados
O suporte deve encerrar chamados concluídos.

---

## Requisitos Não Funcionais

### RNF01
O sistema deve ser responsivo.

### RNF02
O sistema deve possuir controle de acesso.

### RNF03
As informações devem ser armazenadas em banco de dados relacional.

### RNF04
O tempo de resposta deve ser inferior a 3 segundos.
